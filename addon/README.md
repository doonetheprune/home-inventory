# Larder add-on

What you've got, and where. A home inventory for everything in the house, opened from the Home Assistant sidebar.

- Search first, typo-tolerant, with + and − in the results.
- Scan barcodes with the phone camera or a USB scanner; QR labels and NFC tags for places.
- Places with short codes (G2-4), shopping lists by shop, deliveries on the way, unit prices.
- Sensors, actions and events in Home Assistant through the Larder integration, which sets itself up.

See the Documentation tab for setup.
